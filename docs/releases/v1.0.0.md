The first release of MediaTool, a native macOS workspace for local video, audio, and image processing.

## Highlights

- Video conversion, trimming, cropping, rotation, playback speed, frame extraction, and joining clips.
- Audio conversion and extraction, loudness normalization, and sample rate and channel controls.
- Image conversion and resizing, adjustments, watermarks, PDF export, contact sheets, and multiple-size exports.
- Batch queue with command previews, progress, cancellation, and Reveal in Finder.
- Modern and Classic appearances, selectable accents, and light and dark modes.
- Menu bar queue controls, Dock progress, completion notifications, and the updated app icon.

## Install

1. Download **MediaTool-1.0.0-universal.dmg**. It supports Apple silicon and Intel Macs running macOS 13 Ventura or later.
2. Open the DMG and drag **MediaTool.app** to **Applications**.
3. Eject the DMG and launch MediaTool from Applications.
4. Install the processing tools if needed: `brew install ffmpeg imagemagick`. Image-to-PDF output also requires `brew install ghostscript`.

The processing tools are not bundled; media processing runs locally on your Mac.

This build is **ad-hoc signed and not notarized**. If macOS blocks the first launch, follow
[Apple's instructions for opening an app you trust](https://support.apple.com/en-us/102445).

## Verify the download

Download the DMG and its `.sha256` file to the same folder, then run:

```sh
shasum -a 256 -c MediaTool-1.0.0-universal.dmg.sha256
```

See the [README](https://github.com/Ajtn05/MediaTool#readme) for available operations, requirements, and limitations.
